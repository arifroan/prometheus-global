## Brand foundation

- **Core idea:** Bring the fire of knowledge to practical technology.
- **Personality:** Ambitious, disciplined, clear, technically curious and responsible.
- **Visual language:** Deep obsidian backgrounds, restrained gold accents, clean typography, precise line icons and generous spacing.
- **Primary colors:** Obsidian `#08090B`, surface `#101216`, Prometheus gold `#E9B65A`, pale gold `#FFE2A0`, warm white `#F7F4ED`.
- **Voice:** State the ambition confidently, explain the next practical step, and never present planned capabilities as live products.

These are planned directions, not claims of currently operating products.

## Deploy with GitHub Pages

1. Open the repository's **Settings** tab.
2. Select **Pages** under **Code and automation**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. Wait for the Pages deployment workflow to complete and open the published URL.

Repository: https://github.com/arifroan/prometheus-global

## Principles

- Build in small, verifiable stages.
- Prefer open standards and portable technology.
- Protect credentials and private information.
- Be transparent about what is live versus planned.
- Learn operational security before exposing backend services.
- Make the site accessible on mobile, keyboard navigation and reduced-motion settings.
